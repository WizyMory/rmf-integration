# CGMClassic model

- Source: https://fuel.gazebosim.org/1.0/OpenRobotics/models/CGMClassic
- Upstream version: 4
- Author: Roselle Carmen / Open Robotics

The mesh and texture files are the upstream version-4 assets. The two mesh
URIs in `model.sdf` use the local `model://CGMClassic` resource instead of the
upstream HTTP URLs so installed simulations do not depend on a Fuel cache or
network connection.
